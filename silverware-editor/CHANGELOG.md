# Silverware Editor: changelog

## 1.2.0 (2026-11-18)

- Headings, bold text, inline code, code blocks and `---` drawn as in the page's editor, on every SilverBullet version (their sizes, weight, font, spacing and the code block's inset read from the page).
- A link's file icon in the link's colour.
- Other Silverware plugins can highlight code in the editor's languages (Silverware Layout's grid cells do).

## 1.1.0 (2026-11-18)

- Code blocks drawn as blocks and highlighted in their language (the languages SilverBullet highlights: C#, Python, JavaScript, SQL, YAML and more); their backticks shown only where your cursor is in them.
- `---` drawn as a line.
- `==highlights==`, superscripts (`x^2^`) and subscripts (`H~2~O`) drawn as such; quotes with their bar, the `>` hidden; indented code as a block.
- Web addresses drawn as links you click to open; one in a table no longer disappears.

## 1.0.1 (2026-11-17)

- Enter in a list with blank lines between its items continues it without adding a blank line, as SilverBullet's page does.
- Lists (bullets, numbers, tasks) and tables drawn as the page draws them: the text lined up where the page's is, a table in your theme's look.
- Alt+click in the editor (to edit a link) works with SilverBullet's next version too.

## 1.0.0 (2026-11-14)

First release.

- A markdown editor for the other Silverware plugins' fields: markdown highlighted, lists continued on Enter, brackets closed, links to your pages completed, its own undo.
- Silverware Toolbar works over it.
- Tables and embedded files drawn in it (files as Silverware Assets draws them), and links followed on a click (Alt+click to edit one).
- CodeMirror comes with the library: it works offline.
