## Silverware Toolbar

A toolbar by the text selected in a page (as Notion's): favourite actions as icons, *Turn into* a list of block formats, `…` (or the command *Silverware Toolbar: Show actions*, its key `Ctrl-Shift-q` by default) the popup of every action under the toolbar, with a search field, run from the keyboard; the command without a selection shows the toolbar at the caret, the popup open. The plan and the decisions: [docs/silverware-toolbar.md](docs/silverware-toolbar.md) (*Extensions*: the formats domain; *Status and next*: what is done, what is not checked in SilverBullet yet, and the next steps as agreed: start there). Built on the table's principles: a core that knows no module, modules that give actions, a module turned off (`silverware.toolbar.modules.<name>.enabled`) not loaded; formats and actions added (built-in and the user's alike) without changing the core, the domain or a module.
